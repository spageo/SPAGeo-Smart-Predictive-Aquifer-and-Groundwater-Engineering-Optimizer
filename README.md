## 🌊 What is SPAGeo?

SPAGeo is an **AI-powered groundwater modeling platform** built on QGIS. It combines the power of MODFLOW 6 with artificial intelligence to make groundwater modeling faster, more accurate, and accessible to everyone.

### Key Features

- 🧠 **AI Copilot** - Build models through natural language conversation
- 🚀 **Cloud Simulation** - Scale your simulations with cloud computing
- 🌍 **Satellite Integration** - Auto-generate models from satellite imagery
- 📊 **Advanced Visualization** - Stunning 2D and 3D result visualization
- 🔓 **Open Source Core** - Free and open-source community edition

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/spageo/SPAGeo-Smart-Predictive-Aquifer-and-Groundwater-Engineering-Optimizer.git

cd SPAGeo-Smart-Predictive-Aquifer-and-Groundwater-Engineering-Optimizer

# Install from source
pip install -e .
```

### Usage

1. Open QGIS.
2. Go to **Plugins → SPAGeo → Open Copilot**.
3. Type: Create a groundwater model for my study area.
4. Let the AI guide you through the process.
